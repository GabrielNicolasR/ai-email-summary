# Email Summarizer with Gemini AI | Resumidor de Emails com Gemini AI

[English](#english) | [Português](#português)

---

## English

Simple Python project using the Gemini API to automatically summarize emails.

### Technologies Used

- Python
- Gemini API
- python-dotenv

### How to Run the Project

#### 1. Clone the repository

```bash
git clone https://github.com/GabrielNicolasR/ai-email-summary.git
```

#### 2. Install dependencies

```bash
pip install -r requirements.txt
```

#### 3. Create a `.env` file

Inside the project, create a file named `.env`

Example:

```env
GOOGLE_API_KEY=your-key-here
```

#### 4. Run the project

```bash
python app.py
```
